Project Context
This is a React Native mobile app frontend for a crop disease detection and smart farming system. The overall theme must follow the theme that is green agricultural style and feel modern, clean, and farmer-friendly.

Use smooth animations and clean layouts. The UI must feel professional, modern, and visually appealing.

---
