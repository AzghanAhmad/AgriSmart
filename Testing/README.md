# AgriSmart Verification & Validation (V&V)

This folder contains a separate V&V test pack for the project.

## Files

- `TEST_CASES.md`  
  Full 38 test cases mapped to IDs `TC-DD-01` through `TC-INT-38`.

- `RUN_GUIDE.md`  
  Exact commands to run automated tests and how to execute manual validation.

- `execution-template.csv`  
  Template to record test execution status (Pass/Fail), evidence, and notes.

## Scope

This pack covers:

1. Disease Detection
2. Treatment Guidance
3. Task Scheduling
4. Crop Tracking & Monitoring
5. Geotagging & Heatmap
6. Chatbot & Voice
7. Admin Features
8. Profile & Settings
9. Non-functional (performance, security, offline, E2E)

Use `RUN_GUIDE.md` for execution.
